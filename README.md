# Predictive Deadlock Lab

Operating Systems case study: **Predictive Deadlock Prevention Using Contention Analysis and Score Forecasting**.

## Current stage

The [frontend prototype](frontend/) is ready for review. Open `frontend/index.html` to explore the vulnerable and protected browser demonstrations. It includes a Wait-For Graph, event timeline, threat score, contention heatmap, comparison view, and CSV export.

**The current scenarios are demo data.** The next team stages will connect real-thread experiments and runtime analysis. See the [frontend handoff](frontend/README.md) for the event contract and team sequence.
