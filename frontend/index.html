Configurable Threat Scoring Weights & Formula

ThreatScore = round(w_b·B_norm + w_w·W_norm + w_c·C_norm + w_r·R_norm)

METHOD & DEFINITIONS / 04

Understand the mechanism.

A short guide to the operating systems concepts shown in the dashboard.

01 / DETECT
↗

Wait-For Graph

A node is a thread. An arrow T1 → T2 means T1 waits for a lock currently held by T2. In the two-thread, single-instance-lock demo, T1 → T2 → T1 confirms a deadlock.

02 / WARN
⌁

Contention score

Opposite lock order, blocked threads, and longer waits increase the displayed threat score. Crossing the threshold produces an early warning, which is an estimate rather than proof of deadlock.

03 / PREVENT
⇥

Common lock order

In protected mode, every thread chooses A → B before it acquires its first lock. A shared total order prevents circular wait in this scenario. Reordering after a thread already holds a lock would be too late.
