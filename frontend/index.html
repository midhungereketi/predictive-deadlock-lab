Method & definitions · 04

Understand the mechanism.

A short guide to the operating systems concepts shown in the lab.

01 / Detect

Wait-For Graph

A node is a thread. An arrow T1 → T2 means T1 waits for a lock currently held by T2. In this two-thread, single-instance-lock demo, T1 → T2 → T1 confirms a deadlock.

02 / Warn

Contention score

Opposite lock order, blocked threads, and longer waits increase the threat score. Crossing the threshold produces an early warning — an estimate, not proof.

03 / Prevent

Learned common order

A cycle-free contention probe reveals a resource dependency. Protected workers then use one derived order before taking any lock — preventing circular wait.
